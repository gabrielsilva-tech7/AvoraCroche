COMO TROCAR AS FOTOS
1. Coloque a foto dentro da pasta assets.
2. Abra script.js.
3. Na lista products, troque o campo image. Exemplo:
   image: "assets/minha-bolsa.jpg"

COMO ALTERAR PRODUTOS E PREÇOS
- Edite a lista products no início de script.js.
- price usa ponto decimal. Ex.: 119.90.

PUBLICAÇÃO MAIS SIMPLES — VERCEL DROP
1. Abra https://vercel.com/drop
2. Faça login ou crie uma conta Vercel.
3. Arraste avora-site-final.zip para a página.
4. Dê ao projeto o nome avoracroche (se estiver disponível).
5. Clique em Deploy.
6. A Vercel gera um link público HTTPS.

INSTALAR COMO APP
- Android/Chrome: abra o site publicado e use o botão Instalar app quando aparecer, ou Menu > Instalar app.
- iPhone/Safari: Compartilhar > Adicionar à Tela de Início.

IMPORTANTE
A instalação PWA precisa do site publicado em HTTPS; abrir index.html diretamente pelo computador não ativa todos os recursos de app.
